# Resume Website

A clean, modern personal resume website built with HTML, CSS, and a Node.js + Express backend.

## Features
- Responsive design
- Sections: About, Skills, Achievements, Projects, Contact
- Express backend with placeholder API routes (ready for database integration)
- Easy to edit

## How to Run

1. Make sure you have **Node.js** installed.
2. Open a terminal in this folder and run:

```bash
npm install
npm start
```

3. Open your browser and go to: **http://localhost:3000**

## Editing
- Change the text in `index.html`
- Customize colors and styles in `styles.css`
- Add real database logic in `server.js` (look for the `TODO` comments)

## Future Database Ideas
You can easily connect:
- SQLite (simple file-based)
- PostgreSQL
- MongoDB
- Firebase

Just replace the placeholder data in the `/api/` routes.
